# TranslateBetter

A responsive React recreation of the three supplied screens: landing, translation practice, and feedback.

Run `npm install`, then `npm run dev`. Build with `npm run build`.

Includes 100 Chinese-to-English exercises, hints, Chinese speech playback (browser dependent), revision, copying reference answers, saved sentences, and local progress storage. Feedback is clearly labeled sample content; no live AI API is connected. The level setting changes the session label; exercises are currently intermediate.
